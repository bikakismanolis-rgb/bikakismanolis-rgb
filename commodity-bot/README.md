# commodity-bot

Πρόγραμμα που παρακολουθεί 15 ETFs εμπορευμάτων (μέταλλα, ενέργεια, αγροτικά) και
αποφασίζει τι να κρατάει. Προς το παρόν δουλεύει μόνο με εικονικά χρήματα.

## Πώς αποφασίζει

- Κρατάει ένα εμπόρευμα μόνο όταν η τιμή του είναι πάνω από τον κινητό μέσο 200 ημερών.
- Όσο πιο ευμετάβλητο είναι, τόσο μικρότερη η θέση. Ανώτατο όριο 15% ανά εμπόρευμα.
- Μόνο αγορές. Χωρίς μόχλευση, χωρίς short. Ό,τι περισσεύει μένει μετρητά.
- Kill switch: αν το χαρτοφυλάκιο πέσει 15% από το υψηλό του, πουλάει τα πάντα και σταματά.

Όλες οι παράμετροι είναι στο `cbot/config.py`.

## Χρήση

```bash
pip install -r requirements.txt
python run.py backtest     # ιστορική δοκιμή
python run.py signals      # τι θα κρατούσε σήμερα
python run.py paper        # ένας κύκλος εικονικών συναλλαγών (μία φορά τη μέρα, μετά το κλείσιμο ΗΠΑ)
python run.py status       # κατάσταση εικονικού χαρτοφυλακίου
python -m pytest           # tests
```

Το εικονικό χαρτοφυλάκιο αποθηκεύεται στο `state/paper.json` (ξεκινά με 10.000).

## Τι λέει το backtest (2007 έως Νοέμβριος 2026, κόστος 0,10% ανά συναλλαγή)

| | Στρατηγική | Buy & hold |
|---|---|---|
| Ετήσια απόδοση | 1,7% | 1,4% |
| Μεταβλητότητα | 13,0% | 17,5% |
| Sharpe | 0,19 | 0,17 |
| Μέγιστη πτώση | -53,5% | -66,7% |

Με αυτά τα νούμερα η στρατηγική δεν αξίζει πραγματικά χρήματα. Το backtest δεν
περιλαμβάνει το kill switch, ούτε φόρους και συναλλαγματικό κίνδυνο ευρώ/δολαρίου.

## Τι λείπει για πραγματικές συναλλαγές

- Σύνδεση με broker: η κλάση `Broker` στο `cbot/broker.py` είναι η διεπαφή που πρέπει να υλοποιηθεί.
- Ευρωπαϊκά σύμβολα: ιδιώτες στην ΕΕ δεν μπορούν συνήθως να αγοράσουν αμερικανικά ETFs,
  χρειάζονται τα αντίστοιχα UCITS ETCs.
- Στρατηγική με καλύτερα αποτελέσματα από την τωρινή.
