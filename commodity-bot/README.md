# commodity-bot

Πρόγραμμα που παρακολουθεί 19 ευρωπαϊκά ETCs εμπορευμάτων (Χρηματιστήριο Μιλάνου, σε ευρώ)
και διαπραγματεύεται τα τέσσερα με φυσικό πολύτιμο μέταλλο: χρυσό, ασήμι, πλατίνα, παλλάδιο.
Δουλεύει με εικονικά χρήματα. Η σύνδεση με Interactive Brokers είναι γραμμένη αλλά αδοκίμαστη.

## Πώς αποφασίζει

- Κρατάει ένα μέταλλο μόνο όταν η τιμή του είναι πάνω από τον κινητό μέσο 200 ημερών.
- Όσο πιο ευμετάβλητο είναι, τόσο μικρότερη η θέση. Ανώτατο όριο 25% ανά μέταλλο.
- Μόνο αγορές. Χωρίς μόχλευση, χωρίς short. Ό,τι περισσεύει μένει μετρητά.
- Kill switch: αν το χαρτοφυλάκιο πέσει 15% από το υψηλό του, πουλάει τα πάντα και σταματά.

Όλες οι παράμετροι είναι στο `cbot/config.py`.

## Χρήση

```bash
pip install -r requirements.txt
python run.py backtest     # ιστορική δοκιμή
python run.py signals      # τάση σε όλα τα εμπορεύματα και τι θα κρατούσε σήμερα
python run.py paper        # ένας κύκλος εικονικών συναλλαγών (μία φορά τη μέρα, μετά τις 18:00)
python run.py status       # κατάσταση εικονικού χαρτοφυλακίου
python -m pytest           # tests
```

Το εικονικό χαρτοφυλάκιο αποθηκεύεται στο `state/paper.json` (ξεκινά με 10.000 ευρώ).

## Τι λέει το backtest (2010 έως Νοέμβριος 2026, κόστος 0,15% ανά συναλλαγή)

| | Στρατηγική | Διακράτηση 4 μετάλλων | Μόνο χρυσός |
|---|---|---|---|
| Ετήσια απόδοση 2010-2017 | 2,9% | 5,0% | 4,1% |
| Ετήσια απόδοση 2018-2026 | 8,4% | 8,3% | 12,5% |
| Ετήσια απόδοση συνολικά | 5,8% | 6,8% | 8,4% |
| Μεταβλητότητα | 11,5% | 21,2% | 15,6% |
| Sharpe | 0,55 | 0,41 | 0,60 |
| Μέγιστη πτώση | -29,7% | -48,2% | -37,2% |

Η στρατηγική δεν βγάζει περισσότερα από την απλή διακράτηση. Αυτό που προσφέρει είναι
μικρότερες πτώσεις, επειδή βγαίνει σε μετρητά όταν τα μέταλλα πέφτουν (κατά μέσο όρο
είναι επενδυμένη το 50% του χρόνου). Η απόδοση προέρχεται από το ότι τα πολύτιμα
μέταλλα ανέβηκαν αυτή την περίοδο, και αυτό δεν είναι εγγυημένο ότι θα συνεχιστεί.

Τι άλλο δοκιμάστηκε: 48 παραλλαγές τάσης και momentum και στα 19 ETCs (διάφορα χρονικά
παράθυρα, μόνο τα 3, 5 ή 8 ισχυρότερα, εβδομαδιαία ή μηνιαία αναπροσαρμογή). Όλες έχασαν
χρήματα το 2010-2017 και καμία δεν ξεπέρασε σταθερά την απλή διακράτηση. Τα ETCs που
βασίζονται σε futures (ενέργεια, αγροτικά, βιομηχανικά μέταλλα) χάνουν συνεχώς από το
κόστος ανανέωσης των συμβολαίων, γι' αυτό μένουν μόνο υπό παρακολούθηση.

Το backtest δεν περιλαμβάνει το kill switch ούτε φόρους.

## Δεδομένα

Οι τιμές έρχονται δωρεάν από το Yahoo Finance και έχουν λάθη: μεμονωμένες λάθος τιμές και
αλλαγές κλίμακας που δεν έχουν προσαρμοστεί (π.χ. φυσικό αέριο, σιτάρι, καλαμπόκι το 2012-2013).
Το `clean_prices` στο `cbot/data.py` τα διορθώνει. Στα τέσσερα μέταλλα που διαπραγματευόμαστε
δεν χρειάστηκε καμία διόρθωση. Το κακάο (COCO.MI) αφαιρέθηκε επειδή τα δεδομένα του
2012-2014 είναι άχρηστα.

## Interactive Brokers

Ο κώδικας είναι στο `cbot/ibkr.py`. Δεν έχει τρέξει ποτέ απέναντι σε λογαριασμό IBKR,
οπότε η πρώτη χρήση πρέπει να γίνει σε paper λογαριασμό της IBKR.

1. Άνοιξε λογαριασμό στην IBKR και ζήτησε δικαίωμα διαπραγμάτευσης ETFs στην Ιταλία.
2. Εγκατάστησε το IB Gateway, συνδέσου στον paper λογαριασμό και ενεργοποίησε το API.
3. Τρέξε τις παρακάτω εντολές στον ίδιο υπολογιστή.

```bash
python run.py live           # δείχνει τι εντολές θα έστελνε, χωρίς να στείλει τίποτα
python run.py live --send    # στέλνει τις εντολές (θύρα 4002 = paper λογαριασμός)
```

Για πραγματικό λογαριασμό θέλει `IBKR_PORT=4001` και ζητάει πληκτρολογημένη επιβεβαίωση.

Δικλείδες: οριακές εντολές έως 0,5% από την τελευταία τιμή που ακυρώνονται αν δεν εκτελεστούν
σε 60 δευτερόλεπτα, ανώτατη αξία εντολής 2.000 ευρώ, καμία εντολή αν η IBKR δεν αναγνωρίσει
κάποιο σύμβολο. Ο λογαριασμός πρέπει να είναι αποκλειστικά για το bot, γιατί θεωρεί δικό του
κεφάλαιο όλα τα μετρητά σε ευρώ.

Γνωστό κενό: το μέγεθος των εντολών υπολογίζεται από την τιμή κλεισίματος του Yahoo και όχι
από ζωντανή τιμή της IBKR.
